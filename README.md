# 🎯 Customer Segmentation Machine Learning Application

## 🧠 Project Overview
This is an end-to-end Machine Learning application that categorizes customers into distinct business segments based on their purchasing behavior. 

Instead of just outputting a math prediction, this project translates K-Means clustering into actionable business strategies and provides a visual dashboard to explain the AI's decision.
